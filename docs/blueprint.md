# **App Name**: Academia Attendance

## Core Features:

- Attendance Check-In: User-friendly interface for admins to check in students using their Student ID, capturing date, time, name, and ID.
- Admin Authentication: Secure admin login with session timeout and logout functionality to access management dashboards.
- Student Management: Admin panel to view and filter student records.
- Attendance Records: Admin panel to view attendance logs and filter by date or student.
- Responsive Design: Responsive design ensuring the check-in feature, admin panels, and reports are accessible on various devices.
- Student Registration: Admins register students using: Full name, Christian Name, date of birth, Address, Father's phone number, Mother's phone number, Date joining the organization, Student ID (must be unique)
- Excel Upload: Tool to allow admins to upload an .xlsx file containing student information, for adding students.

## Style Guidelines:

- Primary color: Dark Blue (#3F51B5) to evoke a sense of trust and reliability, suitable for an academic environment.
- Background color: Light Gray (#F0F2F5), a desaturated version of the primary, for a clean and unobtrusive backdrop.
- Accent color: Indigo (#673AB7), a color shift of 30 degrees, provides visual interest without overwhelming the user.
- Headline font: 'Space Grotesk', sans-serif, for a modern, techy look in headlines. Body font: 'Inter', sans-serif, for body text and longer content.
- Simple, geometric icons that align with the modern typography, providing intuitive navigation.
- Clean, grid-based layout for a structured and easy-to-navigate admin panel and reports.
- Subtle transitions and loading animations to enhance user experience without being distracting.
